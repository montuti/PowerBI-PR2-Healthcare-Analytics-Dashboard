# PowerBI-PR2-Healthcare-Analytics-Dashboard

## 📌 Project Overview

This project is a Power BI Healthcare Analytics Dashboard created as part of Practical Report 2 (PR2) at Red & White Skill Education.

The dashboard analyzes healthcare patient records and provides interactive insights into patient admissions, billing, hospital performance, insurance providers, and medical conditions using Power BI.

The project demonstrates data cleaning, Power Query transformations, data modeling, visualization, and dashboard design.

---

## 📂 Dataset

Dataset: Healthcare Dataset (Kaggle)

Source:
https://www.kaggle.com/datasets/prasad22/healthcare-dataset

Records: 55,500+

Columns: 15
